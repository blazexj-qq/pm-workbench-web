## 4. 填表铁律（AI 与人工共守）

1. **照契约填**：字段名、选项枚举、格式以此文档为准；新增选项先改契约再改表。
2. **缺失不伪造**：拿不到的值留空或标"待补齐"，禁止 0 / 占位 / 编造。
3. **楼栋进文本、事业部级进 select**：工作台账"楼栋/部位"填具体楼栋名，"项目"只选 3 个事业部级。
4. **软匹配键必填**：要让事项同步进进度计划，专业/标段/工序阶段三字段必须填（否则匹配键为空，永远同步不进去）。
5. **复核闸不可绕**：工作台账未标"已复核"前，不得被视为可信数据写入进度计划或对外推送。
