# AI 代理（阿里云函数计算 FC）部署任务清单 · 项目管理工作台「方案 A」

> **作用**：给工作台"云端代理模式"提供一个**国内可访问**的 AI 中转，替代原来被墙的 Cloudflare Worker。
> **难度**：★☆☆☆☆（复制粘贴 + 填 4 个变量，约 15 分钟）
> **费用**：FC 免费额度内基本 ¥0；大模型按量（通义 qwen-plus 约几分钱/千字，个人每月通常几毛到几块）
> **前置**：需先有① 阿里云账号（你部署飞书 pm-sync 已用过，同一账号）② 一个大模型 API Key（推荐**通义千问**，国内访问稳）

---

## 一、前置确认（打勾）

- [ ] 已登录阿里云，打开 FC 控制台：https://fc.console.aliyun.com
- [ ] 已领大模型 Key：通义千问 → https://dashscope.console.aliyun.com （免费领；或用 DeepSeek https://platform.deepseek.com/api_keys）
- [ ] 本地已准备好代码文件：`项目管理工作台/代理与云端/ai-proxy-fc.py`

---

## 二、第 1 步：新建函数（✅ 粘贴代码）

- [ ] FC 控制台 → **服务与函数** → **创建函数**
- [ ] 创建方式选 **Web 函数**；运行环境选 **Python 3.12**
- [ ] 函数名称填 `pm-ai-proxy`
- [ ] 代码编辑器里的内容**全部删除**，把 `代理与云端/ai-proxy-fc.py` 的完整内容粘贴进去
- [ ] 点 **创建**

> 说明：代码不用改，所有配置走环境变量。函数入口默认就是 `handler(environ, start_response)`，与代码一致。

---

## 三、第 2 步：填环境变量（✅ 最关键）

函数 → **配置** → **环境变量** → 添加以下 4 个（注意大小写）：

| 变量名 | 填什么 | 说明 |
|---|---|---|
| `API_KEY` | 你的大模型 Key（如 `sk-...` 或 dashscope 的 key） | 必填，Key 只在云端，不落前端 |
| `API_BASE` | 通义千问填 `https://dashscope.aliyuncs.com/compatible-mode/v1`；DeepSeek 填 `https://api.deepseek.com/v1` | 模型接口基地址 |
| `API_MODEL` | `qwen-plus` | 默认模型名；前端填了 model 会以前端为准 |
| `ALLOWED_ORIGIN` | **先留空**（=允许所有） | 见下方「⚠️ 关于来源限制」 |

- [ ] 4 个变量填完 → **保存**

> **⚠️ 关于来源限制（ALLOWED_ORIGIN）**：
> - 如果你**本地双击 html 打开**（origin 是 null），这项**必须留空（=*）**，否则会被拦。
> - 如果你**只用线上 GitHub Pages 版**（`https://blazexj-qq.github.io`），可填 `https://blazexj-qq.github.io` 防别人刷你 Key。
> - 新手建议先留空，能跑通再加限制。

## 五、第 4 步：填进工作台（✅ 实测）

- [ ] 打开工作台（线上版或本地双击都行）→ **设置** → **🤖 AI 配置**
- [ ] 「使用模式」下拉选：**云端代理（推荐·Key在服务端）**
- [ ] 「云端代理地址」粘贴第 3 步的地址（如 `https://xxx.fcapp.run`）
- [ ] 「模型名」填 `qwen-plus`（或你用的模型）
- [ ] 点 **保存设置**
- [ ] 进 **AI 助手** 视图 → 粘一段文字（如"周四例会：3#楼消防验收滞后，张工8月20日前整改"）→ 点 **🤖 AI 拆解并预览**
- [ ] 应看到 AI 返回的结构化任务；驾驶舱「🤖 AI 润色」、会议纪要「🤖 AI 精拆 / 润色」也应亮起可用

## 六、排错表

| 现象 | 可能原因 | 解决 |
|---|---|---|
| 提示 `missing API_KEY` | 环境变量没填 / 名字拼错 | 回 FC 配置检查 `API_KEY` 是否大写、有值 |
| 跨域 / origin not allowed | `ALLOWED_ORIGIN` 设了具体域名但本地打开 | 本地用就把该项留空（=*） |
| 返回 4xx | `API_BASE` / `API_MODEL` 填错 | 对照通义/DeepSeek 官方文档核对地址与模型名 |
| 长时间无响应 | 函数冷启动 / Key 无效 | 看 FC 控制台「日志**」确认报错 |
| 提示 `invalid json` | 前端发的内容格式异常 | 一般是代码问题，联系我 |
