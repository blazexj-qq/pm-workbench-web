> **前置**：① 阿里云账号（部署 AI 代理已用过，同一账号）② 已建好的飞书自建应用「每日汇总读取器」（有 多维表格 权限）

## 三、第 2 步：填环境变量（✅ 最关键）

函数 → **配置** → **环境变量** → 添加以下 5 个（注意大小写）：

| 变量名 | 填什么 | 说明 |
|---|---|---|
| `FEISHU_APP_ID` | 飞书应用「每日汇总读取器」的 App ID | 必填 |
| `FEISHU_APP_SECRET` | 该应用的 App Secret（敏感，只在阿里云填，别粘进聊天） | 必填 |
| `BITABLE_APP_TOKEN` | `ZWWebEluhaJSGBsmg95czkEzn0e` | 工作台账所在 Base，一般不用改 |
| `BITABLE_TABLE_ID` | `tblHmMEnDJDrra0p` | 工作台账表 ID，一般不用改 |
| `ALLOWED_ORIGIN` | **先留空**（=允许所有）；只上线 GitHub Pages 可填 `https://blazexj-qq.github.io` 防刷 | 见下方说明 |

- [ ] 5 个变量填完 → **保存**

> **关于来源限制（ALLOWED_ORIGIN）**：
> - 本地双击 html 打开（origin 是 null）→ 这项**必须留空（=*）**，否则被拦。
> - 只用线上 GitHub Pages 版 → 可填 `https://blazexj-qq.github.io` 防别人刷你接口。
> - 新手建议先留空，能跑通再加限制。

## 六、排错表

| 现象 | 可能原因 | 解决 |
|---|---|---|
| 提示 `missing FEISHU_APP_ID / APP_SECRET` | 环境变量没填 / 名字拼错 | 回 FC 配置检查两个变量是否大写、有值 |
| 跨域 / origin not allowed | `ALLOWED_ORIGIN` 设了具体域名但本地打开 | 本地用就把该项留空（=*） |
| 拉取返回空 / 权限错误 | 飞书应用没开多维表格权限，或没加为表协作者 | 去飞书开放平台给应用开权限 + 表加协作者 |
| 长时间无响应 | 函数冷启动 | 看 FC 控制台「日志」确认报错 |
