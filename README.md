# 通用项目管理工作台（前端）

一个**纯前端、单文件**的项目管理工具：台账 + 甘特图 + 场景化周报 + 会议纪要 + 云端备份，双击即可用，无需服务器。

## 🌐 线上地址（GitHub Pages）

> 部署后形如：`https://blazexj-qq.github.io/pm-workbench-web/`
> （根地址会自动跳转到「通用项目管理工作台.html」）

## 📁 仓库文件

| 文件 | 作用 |
|---|---|
| `通用项目管理工作台.html` | 主程序（所有 CSS/JS 内联，单文件离线可用） |
| `index.html` | 跳转页，让 Pages 根地址直接打开主程序 |
| `README.md` | 本说明 |
| `飞书同步代理_部署任务清单.md` | 飞书台账同步的部署步骤（按需） |

> 内部设计稿、复盘文档等**不上公开仓库**（已在 `.gitignore` 忽略）。

## 🚀 怎么更新上线（改完本地 HTML 后）

**方式一：命令行（推荐，一次配好后续快）**
```bash
cd "你的路径\个人成长\项目管理工作台"
git add 通用项目管理工作台.html index.html
git commit -m "更新工作台"
git push origin main
```
推送后等 1~2 分钟，Pages 自动刷新。

**方式二：GitHub 网页拖文件**
打开仓库 → `Add file` → 把改好的 `通用项目管理工作台.html` 拖上去覆盖 → 提交。

## 🔧 调试说明（重要）

- **真调试在本地**：直接双击 `通用项目管理工作台.html`，按 `F12` 开浏览器开发者工具看控制台。改完刷新即可，最快。
- **线上版有缓存**：GitHub Pages 是 CDN 静态托管，改完推上去要等 **1~2 分钟** + 浏览器 `Ctrl+F5` 强刷才生效。别用线上版当实时调试环境。
- **线上版和本地版数据不互通**：两者是不同的"浏览器身份"，各自存在自己浏览器里。换设备/换身份时，用工作台里的「☁️ GitHub 备份」功能导出/恢复数据。

## 💡 功能速览

- 11 维度任务台账、进度甘特图（手写 SVG）
- 场景化周报（例会 / 领导简报 / 问题预警 / 进度专项）
- 会议纪要录入 → 自动拆解任务 → 生成下次会议发言稿
- 随手记一句话建任务 + 语音输入 + 常用模板
- 飞书台账一键同步（需先部署同步代理，见部署清单）
- GitHub 一键云端备份 / 恢复

## 📌 备注

- 纯前端、零后端依赖；除可选 CDN（如导出 Excel 的 SheetJS）外不联网。
- 数据默认存在浏览器本地（IndexedDB），清缓存/换浏览器会没，记得常点「备份到 GitHub」。
