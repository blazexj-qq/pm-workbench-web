# 回归测试（本地工具）

一键验证「通用项目管理工作台.html」的核心计算与渲染是否被破坏。

## 怎么跑
- 双击 `运行回归测试.bat`（已内置 Node 路径，不用自己装环境）
- 或在当前目录命令行：`node 回归测试.js`

## 它在测什么
从 `../通用项目管理工作台.html` **动态抽取主脚本**，在带 DOM 桩的沙箱里加载，
对产值 / 付款 / 量单 / 工期等纯计算函数 + 5 个档案 Tab 渲染 + 工期延期预警 跑 73 项断言。
版本升级后依然可用——**按函数名定位，不依赖行号**。

全绿 ✅ = 钱数没算错、页面点开不崩。
有红字 ❌ = 哪条断言挂了，按名字定位去改。
